# react-native-liquid-glassmorphism

> 🚧 **Under active development.** The public API is not ready yet. This early release reserves the package name while the library is being built.

A React Native library to bring **iOS-style Liquid Glass / Glassmorphism** effects — frosted blur, translucency, and depth — to **both iOS and Android** with a single, declarative API.

## Status

This package is a work in progress. Installing it today gives you a placeholder while development is ongoing.

⭐ **Star / watch the repo to get notified when the first usable version ships:**
https://github.com/himanshu-lal4/react-native-liquid-glassmorphism

## Planned features

- 🍏 iOS-style Liquid Glass surfaces (blur + translucency + vibrancy)
- 🤖 Consistent rendering on Android
- 🎛️ Declarative, customizable API (blur intensity, tint, border, radius)
- 🌗 Light / dark mode aware
- ⚡ New Architecture (Fabric) support
- 🧩 Expo compatible
- 🟦 First-class TypeScript types

## Installation (not functional yet)

```sh
npm install react-native-liquid-glassmorphism
```
